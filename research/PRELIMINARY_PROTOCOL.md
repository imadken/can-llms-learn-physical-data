## A. Constants, source resolution and correctness

Use the public `lerobot/smolvla_base` starting checkpoint, resolving and recording its exact revision. Use the existing compatible LeRobot/LIBERO installation on the DGX Spark where available. Record exact code commits/package versions and the actual controller source. Do not upgrade a shared environment to a moving latest version. Source paths, object identifiers, package compatibility and dimensions are factual implementation matters; they do not authorize alternative models or objectives.

Use LIBERO-Goal, relative Cartesian control, native control frequency, eight current proprioceptive coordinates and seven action dimensions. H=16, ten native flow integration steps. No history, hidden physical parameters, object state, camera or language enters numerical intermediate model inputs. Contact/object geometry is collection or diagnostic metadata only.

The effect token is six-dimensional: end-effector translation change and initial-frame relative rotation logarithm. For K, integrate ideal pose commands from the initial pose. Apply source-verified scaling, clipping, frame/order conventions and limits. Never substitute future measured pose or actual future controller targets. Gripper commands remain in the predicted chunk; observed finger motion is diagnostic only.

### Common numerical coordinates

Keep the exact native coordinate order. State translation is divided by one metre; state axis-angle is divided by pi; each gripper joint position is divided by the maximum absolute physical joint limit in the pinned asset. Action coordinates remain in the controller's declared normalized input range, mapped affinely to [-1,1] if that range differs. No fitted demonstration or evaluation statistics are used. Record every constant in `resolved_environment.json` and apply inverse transforms before execution.

Preserve native image processing and image inputs for S. Disable any second state/action normalization after the state/action transforms above. Zero-pad native state/action slots as required and exclude padded action dimensions from loss. These are fixed pilot conventions, shared across arms and phases, not claims about the checkpoint's original normalization. A source conflict with these conventions is a factual blocker to report, not permission to invent a different transform.

### Final effect-coordinate and token-scale rule

Replace the previous division of effect translation by H times command range and effect rotation by pi with this fixed rule. Before neural training, enumerate every complete H-step training window in canonical episode-ID/start-offset order. Compute the mean mu_i and population standard deviation sigma_i of the six NOMINAL effects eK only. Set s_i=max(sigma_i,f_i), with floors f_i=0.001 metre for translation and pi/180 radians for rotation. Use z_i(e)=(e_i-mu_i)/s_i for both K and D; P receives zero in transformed coordinates. Store the statistics, units, floors, training-window IDs and hashes in resolved_environment.json. No measured D effects, development/evaluation windows, demonstration data or task scores enter these fitted statistics. Do not standardize D separately, clip effect values or refit after training begins.

Initialize the ordinary 6-to-prefix-width linear projector with Xavier-uniform weights, gain 1, and zero bias, using a separate recorded projector RNG stream paired across P/K/D. For each paired training seed, select at most 512 distinct, evenly spaced windows from the same canonical training ordering. On these windows, compute the RMS of the frozen native state embeddings and the RMS of W*z(eK), each over examples and embedding coordinates immediately before the frozen decoder. Compute alpha=RMS_state/RMS_effect using float32 projections and float64 RMS accumulation. If either RMS is below 1e-12, use alpha=1 and report unresolved/degenerate amplitude calibration. Non-finite values are a correctness fault.

Absorb alpha into the initial weights, W_initial=alpha*W; retain zero initial bias. Train this ordinary linear projector thereafter. Use the identical initialized projector, statistics and reference-window selection for P/K/D within each seed. Record alpha, reference IDs, pre/post initial RMS and projector hash. Log K and D normalized-input and embedding-norm summaries; a difference between them is reported rather than separately rescaled. The scaling is an initialization specification, not an extra learned module or performance-tuning stage. Per-example LayerNorm or unit-vector normalization of the effect is excluded because effect magnitude is part of the target. This numerical preparation does not guarantee semantic alignment or acquisition and adds no experiment.

### Architecture and optimization

Use the ordinary trainable linear effect projector initialized by the rule above. Freeze the VLM and native state projector during intermediate training; train the native expert and native action/time/output projections. Preserve autograd through the frozen decoder. Place the state token before the effect token. P uses a neutral zero transformed effect through the same allocated interface. D/K/P share attention masking on 20% of examples. Mask the token in attention, not merely its numeric value.

Use native flow-time sampling and velocity targets. AdamW: learning rate 1e-4, betas (0.9,0.95), epsilon 1e-8, weight decay 1e-10, gradient norm clip 10. Intermediate training: 1,000 updates, effective batch 128, 100-update linear warmup then cosine decay to 2.5e-6 at update 1,000. S: 5,000 updates, effective batch 32, 500-update warmup then cosine decay to 2.5e-6 at update 5,000. The shortened schedules are intentional pilot settings. The current upstream 1,000-update warmup must not silently consume the entire intermediate pilot.

Use BF16 autocast with ordinary floating-point optimizer state when supported. No quantization or model compilation experiment. Microbatch size and gradient accumulation may be adjusted to preserve the effective batch and objective. Numerical incompatibility is reported; do not switch objectives, model, precision semantics or physical interface to make a run complete.

### Required engineering checks

Check single-command translation/rotation conventions, inverse transforms, full snapshot replay, no future-state access in G, flow target sign, padding masks, effect attention masking, projector gradients, frozen parameter integrity and ordinary inference after removing the effect interface. Include a masked-effect invariance check: in deterministic evaluation mode, changing an attention-masked effect vector must leave generated actions unchanged at fixed state, generation noise and parameters. Block every information path, including indirect transmission through another prefix token. State-before-effect ordering alone is not proof of isolation. Paired seeds must match common native weights, data order, action targets, flow noise/time and masks. Parameter hashes and fixed replay tests are evidence, not a new scientific experiment.

Do not continue a dependent experiment with a known correctness failure. Repair ordinary bugs, record them and rerun the affected check. Preserve and label invalid outputs rather than silently reclassifying them.

## B. Shared numerical corpus

Use one fixed collection scene: `push_the_plate_to_the_front_of_the_stove`. Describe it as one prespecified development scene with contact-attempt enrichment. Do not call it a proven best-case or representative sample of the full task suite. Do not replace it based on residual size or success. No demonstrations or demonstration-derived snapshots are used for this corpus.

Attempt 100 episodes with 200 retained control steps each, at most 20,000 transitions. Episode IDs 0-99 alternate two intended reset types: even IDs use native free-motion initialization, odd IDs use a plate-contact attempt. Apply the same fixed native warm-up policy in both; record it. For contact attempts, use a deterministic geometry-aware approach to the plate's negative world-x edge with the native end-effector orientation. Move first above the edge, then towards it; cap the setup prefix at 80 control steps. Resolve plate collision extents, support height and the end-effector-to-finger-pad-pair-midpoint offset at the declared closed-gripper setup configuration from the pinned assets. Target that midpoint at the edge height plus 10 mm after a waypoint 100 mm above it. Cap normalized approach translation at 0.2, set rotation command to zero, and close the gripper during setup. This is a geometry-assisted collector, not unstructured autonomous play. Log setup steps and count their cost, but exclude them from training windows.

After setup, define a fixed local excitation box around that starting end-effector position: x/y within +/-120 mm, z from -50 to +120 mm. Intersect it with any declared controller workspace limits. For each four-step block, independently draw translation commands uniformly in [-0.2,0.2] and rotation commands in [-0.1,0.1] of normalized command units. Filter block commands as u_new=0.5*u_previous+0.5*u_sample, starting at zero. Reflect the translation component if its next ideal pose step would leave the box. Gripper toggles open/close every 32 steps, starting open. Record the RNG seed and every executed action. These commands do not use reward or task success.

Do not teleport into contact. Do not retry until a desired contact fraction, large residual or success score occurs. If the fixed geometry-assisted setup cannot be implemented from the available asset facts, report that blocker rather than silently using expert trajectories. If an attempt reaches its step limit, keep it as an unsuccessful contact attempt. Abort only for simulator invalidity, non-finite state or an actual execution fault, logging the reason; do not replace that episode.

Freeze splits before windowing: episode IDs 0-79 train, 80-89 development, 90-99 exploratory evaluation. This balances intended reset types. Never allow a window to cross an episode boundary. Distinguish intended contact attempts from actual robot-object contacts measured using simulator contact records. Report all attempts, actual retained steps and achieved contact fractions. Object-table contacts alone do not count as robot-object contact.

## C. Preliminary 1: measured versus nominal effects

**Question:** What discrepancies exist under this declared controller, collector and nominal map, and is part of their structure predictable from permitted numerical inputs?

Use nominal mechanics only. No mass, friction, damping or delay intervention.

From each of the ten exploratory-evaluation episodes, take full snapshots at retained offsets 0,16,...,144, if present: at most 100 snapshots. Snapshot simulator state, controller targets/internal state, gripper internal state, RNG and timing state relative to the next control action. Generate two independently seeded reference chunks from the fixed bounded excitation rule at each snapshot. Reset and record the generator's filter state to zero, block phase to zero, gripper phase to open, and local box anchor to the snapshot pose; use ideal pose integration for boundary handling. Materialize and save the complete action array before any replay. Replay that identical saved array twice from the identical complete snapshot; no future measured pose may alter the reference array. Maximum: 400 replays, each 16 control steps. Missing/invalid snapshots are reported and not replaced by selected favorable cases.

For translation, report Euclidean endpoint discrepancy in millimetres. For orientation, report the geodesic norm of Log((Q_K)^T Q_D) in degrees, with Q_D and Q_K the corresponding relative rotations. Do not interpret subtraction of rotation-vector coordinates as a physical angular distance. Log finger displacement separately. Do not create an unscaled mixed-unit residual norm.

Compare residual distributions for actual robot-object-contact and no-contact windows; show intended reset categories and duplicate replay variability separately. Log clipping, action magnitude, command-boundary contacts, tracking timing and invalidity. Residuals can include nominal-map approximation, lag, saturation and contact; do not label all discrepancy as physical understanding.

One small ridge diagnostic is allowed: features are r_t plus the flattened 16x7 action chunk; targets are translation residual and the three-dimensional rotational discrepancy logarithm. Standardize features with training episodes only; fit an unpenalized intercept and minimize mean squared target error plus 1e-3 times squared coefficient norm. No hyperparameter search, neural predictor, object state or contact label input. Compare held-out error against zero residual and the training-mean residual, separately by translation and rotation. Also report held-out squared-error reduction 1-SSE_ridge/SSE_training_mean, separately for translation and rotation, overall and by actual contact stratum, using the same fitted predictor. Allow negative values; if the denominator is zero or numerically negligible, mark the ratio undefined and retain absolute errors. This is fitting a linear diagnostic, not 'no model training at all.'

High predictability supports a simple explanation of the discrepancy but does not identify controller calibration as its cause or show equivalence to training on calibrated labels. Low predictability is not evidence of complex or useful physics. Report free-motion residuals and tracking/nominal-map limitations explicitly.

Produce one two-panel residual/structure figure plus its source CSV. A small, unstructured or noisy residual is a reported finding. It does not stop Preliminary 2 if the implementation and measurements are valid, and it does not authorize a new collector or paper pivot.

## D. Preliminary 2: small effect-conditioned acquisition

**Question:** Does the implemented intermediate objective learn usable conditioning, within a small exploratory budget?

Train exactly P/K/D with paired training seeds 101 and 202, using the shared corpus, common initialization and fixed settings above. Six runs maximum. No downstream P/K/D task training. Save final and common 250-update checkpoints; use final scheduled checkpoints for the full pilot report, or the latest completed common checkpoint if interrupted by the resource cap. Never choose a checkpoint based on favorable outcomes.

For evaluation, take the first 16 valid snapshots from each intended reset category in Preliminary 1's fixed ordering, at most 32 snapshots. Each has two reference actions and hence two reachable measured goals. Do not select by residual or target separation. Record coincident or nearly identical targets rather than replacing them. Use one fixed generation-noise draw per snapshot and training seed, paired across models and conditioning modes. Report the number of source episodes and repeated snapshots; target-level scores from one episode are not independent training replicates.

For D and K, test the same common physical endpoint under three modes: supplied goal, attention-masked effect, and the alternate reachable measured goal from that same snapshot. Generate a full chunk from noise, then execute all 16 actions without replanning. Score each action chunk against both the original and supplied measured target. P receives no informative effect and its single generated chunk is reused for the paired goals; repeated scoring is not independent sampling.

Also report K's native acquisition: condition it on each nominal goal and compare G(r_t,A_generated) against that goal. This analytic nominal attainment is not physical attainment. D's native goal is already the measured endpoint. Keep K's native metric separate from the common physical-target test, which additionally tests whether nominal conditioning transfers to realized targets. Report token-range coverage for that common target test; no clipping or target exclusion to improve results.

Report translation error, rotation geodesic error, action changes and exploratory attainment within both 10 mm and 5 degrees. Different actions alone show sensitivity; improved attainment of the supplied goal is stronger evidence. Avoid a D-versus-K claim based on incomparable native losses. Show both training seeds individually; the limited pilot does not establish training-seed significance or equivalence.

At most 1,024 generated chunks cover the prescribed cases, including the extra K diagnostic; reuse identical masked/P generations rather than rerunning them. Keep one acquisition figure, with source CSV and per-target records.

### Predeclared acquisition-evidence criterion

Classify native acquisition separately for K and D. Use K's nominal-map endpoint space and D's measured endpoint space, with the existing 10 mm and 5 degree joint-attainment tolerances. In each of the two training seeds, require (a) matched conditioning to improve joint attainment by at least ten percentage points over both the attention-masked condition and P; and (b) matched conditioning to have strictly lower mean translation error and no worse mean rotation error than the alternate-target condition, or strictly lower rotation error and no worse translation error. For K, its already generated nominal-goal pair supplies the alternate-target comparison by rescoring the paired output; score existing masked and P outputs through G. No extra generations or training runs are required.

Meeting both requirements in both seeds is labelled 'positive exploratory acquisition evidence.' Meeting them in only one seed is labelled 'mixed exploratory evidence.' Otherwise report 'acquisition not demonstrated within this pilot budget,' along with all continuous errors, attainment differences, source-episode counts and any directional improvement. If the targets barely differ or controls already saturate, describe the diagnostic's limited discrimination. An incomplete checkpoint remains explicitly partial. The ten-point convention is descriptive, not a significance test, proof of convergence, RSS requirement or submission gate. Failing it does not authorize extended training or imply broken code. Only a failed implementation invariant identifies a concrete correctness defect.
